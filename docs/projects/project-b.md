# 项目 B · 数据可视化工具

## 项目背景

为运营团队打造的实时数据看板，目标是让非技术人员能够自助完成数据查询、图表制作与下钻分析。

## 核心功能

- **拖拽式看板编辑**：通过拖拽组件搭建自定义看板
- **30+ 图表类型**：折线、柱状、饼图、热力图、桑基图等
- **下钻分析**：从汇总数据下钻到明细
- **数据源接入**：支持 MySQL、PostgreSQL、CSV、API
- **告警规则**：数据异常时自动通知

## 技术选型

### 前端
- **Vue 3 + Composition API**
- **ECharts** + **D3.js**：满足从通用到定制的图表需求
- **Pinia**：状态管理
- **Vite**：构建工具

### 后端
- **Python + FastAPI**：高性能异步 API
- **ClickHouse**：OLAP 场景下的高性能查询
- **Celery**：异步任务队列

## 关键挑战

### 1. 复杂图表的性能

当数据点超过 1 万时，ECharts 默认渲染会出现卡顿。通过**数据采样** + **LOD（Level of Detail）**优化，保证 10 万级数据点流畅渲染。

### 2. 数据安全

通过**SQL 注入检查** + **列级权限控制** + **查询超时**三层防护，避免运营人员误操作导致系统问题。

### 3. 自定义图表

基于 D3.js 封装了一套图表 SDK，让业务方可以基于通用图表扩展自定义组件。

## 项目成果

- 替代了 2 个商业 BI 工具
- 运营人员自助分析覆盖率 80%+
- 日均查询 5 万次
