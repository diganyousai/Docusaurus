# 项目 A · 内部协作平台

## 项目背景

为团队搭建的内部协作工具，目标是替代现有的 Notion + Slack + 飞书组合，让团队在一个地方完成文档、任务、沟通。

## 核心功能

- **实时文档编辑**：基于 CRDT 算法，支持多人同时编辑
- **任务管理**：看板视图、列表视图、自定义工作流
- **评论与通知**：文档级评论、@ 提及、邮件与 Web 通知
- **权限管理**：组织 → 空间 → 页面三级权限

## 技术选型

### 前端
- **React 18** + **TypeScript**：组件化、类型安全
- **Vite**：极快的开发体验
- **Yjs**：CRDT 协同编辑算法
- **Tailwind CSS**：原子化样式

### 后端
- **Node.js + NestJS**：分层架构，依赖注入
- **PostgreSQL**：主库，使用 JSONB 存储文档
- **Redis**：缓存 + WebSocket 适配
- **WebSocket**：实时同步

## 关键挑战

### 1. 实时编辑冲突处理

采用 Yjs 框架解决 CRDT 合并问题，最终用户在弱网环境下也能保持一致。

### 2. 大文档性能

超过 10 万字的文档会出现卡顿，通过**虚拟滚动** + **分片加载**优化，首屏渲染 < 200ms。

### 3. 离线编辑

使用 **IndexedDB** + **Service Worker** 实现离线编辑，网络恢复后自动同步。

## 项目成果

- 团队日活从 30 提升到 200
- 文档协作延迟 < 100ms
- 替换了 3 个外部工具，每年节省成本约 12 万
